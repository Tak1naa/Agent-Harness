# 材料重建

代码和实验入口的安装不依赖Office运行时。材料生成另需python-docx、LibreOffice及已安装的Codex artifact-tool运行时。

- `python scripts/make_content.py`：重建逐页内容JSON与921字讲稿。
- 用文档运行时执行 `scripts/build_report.py`：重建DOCX，随后必须使用documents技能的render_docx.py渲染检查。
- 将 `scripts/build_deck.mjs` 复制至build目录，build/node_modules链接到artifact-tool包目录。配置PRESENTATION_SKILL_DIR、RUNTIME_PYTHON、RUNTIME_NODE_MODULES后用该运行时的Node执行。最终文件已存在时请先选择新输出文件名；finalizer不覆盖成品。需按技能要求执行artifact authoring marker。
- `python scripts/build_demo.py`：从真实path-01与服务器JSON重建离线演示。复制record_video.mjs至build，使用带浏览器/FFmpeg的Playwright运行时录制；再用FFmpeg转H.264、yuv420p、20秒MP4。视频无旁白，配合讲稿演示。
- `python scripts/package_delivery.py`：按白名单打包，排除.env、虚拟环境、原始PDF和个人资料，附SHA256SUMS.json。

若实验结果变更，先核验JSON，再修改报告源文案与presentation_content内容，重新渲染全部页，避免手工替换数字后失去证据链。当前材料记录的是工程验收阶段，真实A/B/C尚未运行。

# Harness 会话客户端

本客户端把任务输入、模型对话、文件上下文、工具过程和修改审批放在同一界面。主入口是会话，而不是研究统计。研究与评测保留在独立的 `/research` 页面。

## 启动

完成 README 中的依赖安装后，从项目目录执行：

```bash
bash scripts/start_web.sh
# 或指定工作区和端口
.venv/bin/python -m safety_harness.web --workspace "$PWD" --port 8765
```

浏览器打开 http://127.0.0.1:8765/ 。程序只监听本机回环；服务停止后网页不能继续工作。如果运行在既有实验服务器上，使用现有 SSH 链路做本地端口转发，不开放防火墙或公网监听。

密钥配置位置为项目根目录 `.env` 的 `DEEPSEEK_API_KEY=` 后面。填写后重启服务；密钥不在网页显示、不进入会话或容器。没有密钥也可浏览项目文件和历史研究统计。

## 一次任务怎么做

1. 点击“新会话”，输入任务。Enter 发送，Shift+Enter 换行；Ctrl/Cmd+K 新建会话。
2. 在项目面板搜索和打开文件，点击“引用到对话”。最多引用4个文件，Agent按需调用读取工具。
3. Agent响应实时显示；每次工具调用会展示名称、参数、运行状态和实际返回，可以展开核对。
4. Agent提议文件修改后暂停。在“修改”面板审查差异，选择“应用修改”或“拒绝”。只有点击应用才写入；文件在提案后被其他工具或成员更改时，拒绝覆盖，需重新提出修改。
5. 审批完成后发送下一条消息继续。停止按钮会请求在当前API响应或容器调用返回后的安全点停止；已经完成的操作和费用保留。

可以直接输入：

- `读取 safety_harness/experiment.py，用简单中文解释执行流程。`
- `分析 data/controlled/command-01/buggy.py，解释实际静态告警。`
- `用参考测试在隔离容器中验证 path-01，比较缺陷版和修复版。`
- `读取最近 benchmark 的真实结果，说明结论与局限。`
- `阅读 docs/客户端使用.md，为启动部分补充说明，提出修改供我审查。`

## 当前能力与边界

这是浏览器中的桌面式客户端，后端是**本项目自有的有界 Harness Agent**，使用 DeepSeek API 的流式 function calling；不是官方 DeepSeek Harness SDK 会话，也尚未打包原生桌面安装程序。官方 SDK 的初始化/MCP 探索保留在 `integrations/deepseek-harness/`，不混作此客户端的完成证据。

| 工具 | 实际行为 |
| --- | --- |
| list_files / read_file | 在允许的项目文本目录中列出、读取文件 |
| analyze_python | 调用已有 Bandit 与 AST 分析，不执行目标 |
| run_security_case | 运行30个已知受控样本之一，使用参考或受限自定义测试，在 rootless 容器中配对执行 |
| benchmark_summary | 读取已保存的本轮研究统计，不启动新实验 |
| propose_edit | 生成单文件差异并等待确认，不自动写入 |

不提供宿主机 Shell，也不运行任意项目命令。文件访问排除隐藏路径、符号链接、私有日志、生成样本及密钥；冻结数据可读不可写，历史结果不可改。研究页的模型评测严格复用既有实验入口；聊天中调用的参考测试和交互验证不计入冻结 A/B/C 结果。

每轮最多6次模型请求，每次输出上限2048 Token，每次回复最多8个工具调用。使用 `deepseek-flash`，不思考模式；模型请求失败不自动重试。共用 `results/private/budget.json` 的100元总预算，按输入字节和最大输出保守预留，预留金额不是实际账单。模型API调用在容器外完成。

当前仅允许一个聊天任务运行。会话保存于 `results/private/client/<会话编号>/session.json`；配对运行的目标哈希、镜像ID、测试日志也保存在该私有会话目录。页面重载可续看，服务重启会将未完成任务标记为中断，用户可发新消息继续，不自动重放操作。

## 验证入口

```bash
.venv/bin/python -m pytest -q -m 'not container'
node --test tests/frontend/client.test.cjs
RUN_CONTAINER_TESTS=1 HARNESS_TEST_IMAGE=localhost/bjtu-safety-harness:0.2 \
  .venv/bin/python -m pytest -q tests/test_container.py
```

测试区分模型替身的协议检查与真实API联调。客户端协议测试验证会话续接、流式解析、工具取消、审批写入、并发文件修改保护、路径限制和HTTP同源边界；不把这些替身测试称为真实模型端到端测试。

前端测试需要 Node.js 20+，不需要 npm 安装依赖；覆盖会话草稿/引用隔离、延迟请求返回和用户新输入保护。草稿在当前页面内按会话保存，刷新页面会清空未发送的草稿。

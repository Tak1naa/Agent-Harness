# 2026-10-25 Benchmark 试跑结果

## 自建受控动态基准

24个人工构造评测样本（路径穿越、命令注入、SQL注入各8个），三组各运行一次，共72次试验。使用 `deepseek-flash` 非思考模式，temperature=0，每次响应最多1800输出Token，每次试验至多三次调用。不是24个独立真实项目，也不是公开排行榜结果。

| 方法 | 配对复现 | 可运行 | 修复版误报 / 有效判定 |
|---|---:|---:|---:|
| A：源码直接生成 | 20/24（83.3%） | 23/24 | 0/24 |
| B：增加Bandit告警 | 22/24（91.7%） | 24/24 | 0/24 |
| C：再增加AST上下文 | 22/24（91.7%） | 24/24 | 0/24 |

“配对复现”要求同一测试在缺陷版触发真实安全违规，在修复版通过。A组最终状态为20违规、3未触发、1测试错误；B/C各22违规、2未触发。安全版本无未判定项。分支覆盖只在有分支的5个有效记录上计算，三组均为80%，不能解释为整个数据集覆盖率。

本轮B/C比A高8.3个百分点；C与B持平，不能声称本轮证明AST带来额外收益。每样本只重复一次，样本含相似模板，结果仅作描述，不作统计显著性或泛化结论。与历史冻结批次分别报告。

失败案例：`path-04`和`path-10`三组均未复现；A组还在`command-08`未触发，在`sql-08`出现测试错误。`path-10`的C组末轮测试尝试固定绝对路径、被过滤的相对路径或不存在的中间目录，未取得隔离临时目录的验证秘密；`command-08`的A组测试主要回显标记路径，没有创建探针所需的标记文件。这些失败可能涉及输入选择与测试环境/判据的配合，不能直接归为“目标安全”。

原始记录在 `results/private/benchmark-20261025`。公开统计：

- `analysis.json`：全量、预算内比较、网络事件、用量与核验结果。
- `full-audit.json`：逐样本状态、响应次数、首次触发及错误统计。
- `full-summary.csv`、`within-budget-summary.csv`：由原始日志重建的统计表。
- `config.json`、`provenance.json`：镜像、参数、源码与数据指纹。
- `evidence-verification.json`：72次试验、107份成功响应证据一致性核验通过，0错误。

记录到5次API连接超时，均保留为不确定请求；加上107份成功响应，共112次请求预留。每个trial将失败计入后仍不超过三次请求，故没有剔除匹配块。网络处理规则在首次超时后、首次续跑前记录，不能称为事先预注册。

成功响应合计输入91,545、输出21,271 Token，按高峰输入全未命中2元/百万、输出8元/百万的保守估算为 **0.353258元**，不含失败请求未知实际用量。共享账本本轮增加预留 **2.540022元**（含失败请求及最大输出预留），不是实际账单。价格来源：[DeepSeek官方中文价格页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)，核对日期2026-10-25。

## SecurityEval 外部静态诊断

对[官方仓库固定提交](https://github.com/s2e-lab/SecurityEval/tree/6f4fb70f782c6d47b02ea24341e8ef8c1eb04a6a)的121个 `Insecure_code` 原样分析，0个目标执行、0次模型调用。全部语法有效，无Bandit工具错误。每个原始文件哈希和分析记录已交叉核对。

| 静态指标 | 样本数 / 全量 | 比例 |
|---|---:|---:|
| Bandit至少一条告警 | 48/121 | 39.7% |
| AST至少一个敏感调用 | 18/121 | 14.9% |
| 二者至少一个线索 | 53/121 | 43.8% |
| Bandit告警CWE与样本编号精确相等 | 23/121 | 19.0% |

上述是线索覆盖，**不是准确率或已确认漏洞检出率**。任意告警可能与标注漏洞无关；AST只是名称匹配；CWE精确相等不处理父子分类且不验证告警位置。上游不安全标签未独立核验，缺少安全负例，不能计算精确率和误报率。三个主要CWE（22/78/89）合计8份样本，7份有任一静态线索，仍未动态确认。

完整逐样本诊断在 `securityeval-static.json`；原始代码与121份分析报告位于 `results/private/securityeval-static-20261025`，不随公开统计重新分发。该数据集有多种函数入口、Web请求、数据库和文件资源，尚未适配到本项目统一的 `handle(value, root)` 动态接口。

复跑步骤及限制见[benchmark说明](../../docs/benchmark.md)。此次只增加诊断脚本、统计和文档，未更改核心提示词、探针或测试策略；23个非容器回归测试通过，6个独立容器测试未另行重跑，本轮真实动态评测使用现有v0.2镜像完成。

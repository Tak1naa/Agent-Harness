# 证据目录

reference：冻结30对样本的人工参考测试原始结果，config保存镜像与manifest哈希；summary可由CLI重新生成。每个样本结果包含目标/测试sha256、状态、真实事件、覆盖率及执行时间。

server：相同镜像在实验服务器上复现三类代表案例，每类缺陷版和修复版均保留。

unit-tests.xml：21项离线单元／MCP协议测试，其中测试替身只验证批处理调度，不算模型效果。container-tests.xml：5项真实容器测试，包含三类配对、超时与Hypothesis。

dsh-integration.json：SDK无Key初始化记录；未发送模型prompt。verification.json：以上证据汇总。

static：当前path-01静态分析。smoke：开发期间早期冒烟记录，可能与最终冻结样本不同，仅作开发历史，不进入报告统计和交付包。

所有 reference 测试为人工定义。失败分类测试通过只表明分类逻辑符合当前测试边界，不意味着已穷尽所有异常或恶意目标行为。

2026-10-22新增：`unit-tests-20261022-v2.xml`（23项通过）、`container-tests-20261022-v2.xml`（6项通过）。后者使用独立v0.2镜像，新增生成测试错误行定位，保留v0.1镜像。

真实模型开发集试验分别在 `private/pilot-20261022`、`private/pilot-20261022-v2`，包含模型输出、每次生成提示、容器执行JSON、配置和源码哈希。`private` 默认不进入Git；开发轮次不进入交付包。本次交付包仅明确纳入冻结评测目录供本地核验。它们只含6个开发样本，每组每样本1次，不能作为24个冻结评测样本的结果；不同开发轮次不能混合分析。

批次完成后重建统计并校验证据：

```bash

```
